# 🚀 Food-Bridge – Zero Hunger & Smart Food Redistribution System

## 📌 Problem Statement

**Zero Hunger**

Match surplus perishable food to demand centres using expiry-aware routing and dynamic allocation - minimising food waste while maximising meals delivered to those in need.

---

## 💡 Solution

Food-Bridge is a platform that connects food donors with receivers to enable the redistribution of surplus food efficiently.

* 🌍 Promotes sustainability by significantly reducing food waste
* 🔄 Enables the seamless donation and redistribution of surplus food
* 🤝 Connects donors (restaurants, individuals) and receivers (NGOs, charities) on one centralized platform
* 📊 Improves resource utilization and ensures excess food reaches those in need

---

## 🛠️ Tech Stack

* **Frontend:** React.js / Next.js / Tailwind CSS / TypeScript
* **Backend:** Node.js / Express.js
* **Database:** Firebase (Firestore, Authentication)

---

## ⚙️ Features

* 🔐 User Authentication (Login / Signup for Donors & Receivers)
* 📊 Role-based Dashboards for Donors & Receivers
* 🔄 Real-time Data Handling and Synchronization
* 📱 Responsive, Mobile-first UI
* 🔗 Secure Backend Integration

## 🚀 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Adithyadprabhu/Food-Bridge.git
cd Food-Bridge
```

### 2️⃣ Install Dependencies

```bash
# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
npm install
```

### 3️⃣ Run the Project

**Run backend**
```bash
cd backend
npm run dev
```

**Run frontend**
```bash
cd frontend
npm run dev
```
